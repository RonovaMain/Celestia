# Celestia — смена голоса офлайн (RVC v2) для Android

Пакет `dev.ronova.celestia`. Kotlin + Compose (Material 3 / Material You), ONNX Runtime только на CPU, arm64-v8a.
В манифесте нет разрешения INTERNET: приложение физически не может выйти в сеть.

## Как пользоваться
Голоса → выбрать .pth (+ по желанию .index) → «Конвертировать и добавить». Index можно добавить или заменить позже в карточке голоса. Затем «Использовать для конвертации» → выбрать аудио → «Конвертировать».
Настройки: Pitch ±24, Index Rate (сходство с голосом), Protect, RMS Mix, Температура; RMVPE/FCPE; микшер с минусом.

## Озвучка текста (вкладка «Озвучка»)
Текст → системный синтезатор речи Android (офлайн-голоса телефона, любой установленный язык, в т. ч. русский) → голос RVC.
Тембр основы всё равно заменяется, поэтому от синтезатора нужны лишь внятность и интонация. Можно выключить RVC («Только озвучка»).
Модели грузятся строго по очереди: синтезатор (живёт в своём процессе) закрывается до загрузки RVC. Если русского голоса нет —
«Настройки TTS» / «Установить голосовые данные» прямо на вкладке.

## Разделение вокала и минуса (вкладка «Разделение»)
MDX-Net из Ultimate Vocal Remover (Voc FT — основная, Kim Vocal 2 — запасная), STFT/iSTFT на Kotlin, ONNX Runtime CPU.
Трек режется на куски ~6 с, результат пишется на диск потоком (в памяти только исходник и один кусок), модель выгружается после работы.
Результат — папка песни в приложении (vocals.wav + instrumental.wav). «Использовать в RVC» подставляет вокал и минус на экран конвертации
(микшер и RMVPE включаются автоматически), кнопку «Конвертировать» нажимает пользователь. Экспорт: WAV, FLAC (без потерь), M4A (AAC 256).

## Модели (скачиваются в CI)
- MDX-Net Voc FT и Kim Vocal 2 (UVR, MIT) — TRvlvr/model_repo, запасное зеркало seanghay/uvr_models; если скачать не удалось, сборка не падает, а приложение предложит выбрать свой .onnx (вход 4×3072×256)
- ContentVec vec-768-layer-12 — NaruseMioShirakana/MoeSS-SUBModel (в репозитории указана лицензия GPL-3.0)
- RMVPE — Scicom-intl/rmvpe-onnx (MIT; веса RVC-Project)
- FCPE — Scicom-intl/fcpe-onnx (MIT; CNChTu/FCPE)
